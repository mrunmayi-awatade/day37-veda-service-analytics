# Day 37 – Veda Technology Business & Service Analytics

## Project Overview
This project analyses simulated IT service inquiries, digital service inquiries, customer requests and service demand using Python.

## Objectives
- Analyse IT service inquiries.
- Evaluate digital service performance.
- Study customer service requests.
- Segment customers based on request activity.
- Identify service demand patterns.
- Generate business insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Activities
- Dataset creation and exploration
- Data cleaning
- IT service inquiry analysis
- Digital service channel analysis
- Customer request analysis
- Customer segmentation
- Service demand analysis
- Business insights generation

## Files Included
- day37_veda_service_analytics.ipynb
- day37_it_service_analysis.csv
- day37_digital_service_analysis.csv
- day37_customer_request_analysis.csv
- day37_customer_segmentation.csv
- day37_service_demand_analysis.csv
- day37_business_insights_report.txt

## Learning Outcomes
Learned how to analyse service inquiries, understand customer behaviour, segment customers and identify service demand using Python.

## Dataset Note
This project uses synthetic data for educational purposes and does not contain confidential Veda Technology information.
